# AtSea Qibla site

Public pages for the AtSea Qibla Android app, served with GitHub Pages:

- `index.html` — app home page
- `privacy.html` — privacy policy linked from Google Play and from the app (More → Privacy Policy)

The app opens `https://hisyamz-tech.github.io/atsea-qibla-site/privacy.html`, so keep this repo name and file name.
